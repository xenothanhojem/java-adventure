A.1 ASCII / UNICODE (First 127 Characters)  
  
 
Each character found on the keyboard has a 
unique associated integer code value called its 
Unicode or ASCII code value. 
 
You may have some difficulty getting the first 31 
ASCII characters to print on the screen or printer. 
This is because they are control characters with 
special meanings. 
 
e.g. 9 is tab, 
 10 is line feed 
  27 is escape   
 (Esc on the keyboard) 
 
 7 is the bell for sound 
 32 is a space 
 
You may also find that the printer prints different 
characters on paper to those that you see on the 
screen. If this happens, consult your printer 
manual and find out how to change the settings. 
 
Although Java uses 16-bit Unicode instead of 7- 
or 8-bit ASCII code, the first 127 ASCII values, 
representing the most common keyboard 
characters, are "converted" by Java into Unicode 
and can therefore be used to cast characters from 
the integer ASCII values.
