3.1 Characters 
A variable of the primitive data type char holds a single character. Character values are written 
between single quotation marks:  
 char c = 'a'; 
Characters are represented in Java by the Unicode character set which is a set of integer code 
values. More information on Unicode can be found at: http://www.unicode.org. 
You can imagine the Unicode set as a big table of all the characters on the keyboard as well as many 
more characters from different languages, Braille patterns and all sorts of symbols. Each character 
has a unique number so that the computer can identify one from another.  
For example, the lowercase letters of the alphabet are represented by the actual integer values 97, 
98, …, 122, i.e. 'a' is represented by the integer 97, 'b' is represented by the integer 98, etc. Here 
are some more examples:

3.1.1 Escape Sequences 
There are some special characters which we use quite often but which do not have single character 
symbols on our keyboard. For example:  the newline character (return or enter) and the tab character. 
Although these have unique Unicode values, it is more convenient (and understandable) to express 
them using something called an escape sequence which is a backslash (\) followed by a special 
character.  
Escape sequence Meaning 
\n Move the cursor to the beginning of the next line (equivalent to pressing the 
Enter key) 
\t Move the cursor to the next tab stop 
\\ Display a backslash character 
\' Display a single-quote character 
\" Display a double-quote character

3.2 Strings 
A String is a series of characters treated as a single unit. The String data type is not a primitive data 
type, like int, char, etc. As we have seen, String is a class. However, Strings are fundamental to Java; 
the String class therefore has a number of features that we don't find in other classes. One such 
feature is the way a String object may be initialised: 
 String leader = "Mandela"; 
Here the object leader is created without using new, as we do for Gogga and Color objects. This is a 
special short-cut case for strings. The statement above is in fact equivalent to the following: 
 String leader = new String("Mandela"); 
As previously mentioned, the '+' operator is used for concatenating strings. The '+' operator can 
also be used to concatenate strings and characters, for example: 
String st = "Run"; 
System.out.println(st + '!');    //These 2 statements print: Run! 
In addition to the plus operator there are many methods you can use with objects of the String class. 
One very useful method is the method charAt(i) which returns the character at position i in a String. 
The first character in a String is at position zero, the second character is at position one etc.

3.3 Typecasting 
There are two data type conversions in Java:  
1. A widening conversion, which occurs when a value of one type is converted to a data type 
that has a larger range of values. Java performs widening conversions automatically, such as 
when an integer value is assigned to a variable of the double data type.  
    E.g. double realNum; 
    realNum = 7; 
2. A narrowing conversion, which occurs when a value of one type is converted to a data type 
that has a smaller range of values (such as double to integer). Narrowing conversions are not 
always safe, because data can be lost if the value is outside the possible range of values in the 
new data type. 
Java can be forced to perform a narrowing conversion using a construct know as a typecast, or cast 
for short, by placing the name of the desired data type in round brackets before the value to be 
converted.  
 E.g.  int num; 
   num = (int) 13.456; 
Firstly, we will look at converting real numbers to integers.

3.3.1 Cast Operators and Integer Division 
When an integer is divided by another integer, the decimal part of the result is lost (truncated) even if 
it is assigned to a float or double variable. For example, consider the following: 
 double x; 
 x = 15 / 2; 
 System.out.println(x); 
The output of this portion of code would be:  7.0   
This is because the right-hand side of the assignment statement (15/2) is evaluated first, producing an 
answer of 7. This integer is then assigned to (stored in) the variable x, which is of type double. This 
results in the integer 7 being converted into a double, so the println statement outputs the real number 
7.0. 
To prevent this integer division, we can use a cast operator as follows:  
 x = (double)15 / 2; 
The cast operator, (double), converts (or casts) the integer immediately in front of it (15) to a double 
(real number) before the division takes place. The division becomes 15.0 / 2. The result of this is 
therefore 7.5 (rather than 7), which is assigned to x.   
3.3.2  Converting Between Variable Types 
Cast operators are available for several data types and are formed by placing parentheses around the 
data type name immediately in front of the value to be converted. Java allows casting to be used for 
some data type conversions, such as converting from a char type to an integer or a real number and 
converting between integer numbers and real numbers.  
You cannot, however, use casting to convert from String to integer or double. 
While the println method will convert all types to Strings before displaying them, we use methods to 
change from String to integer and String to double. We use the parseInt() method of the Integer 
class to convert a String to an integer and parseDouble() of the Double class to convert a String to 
a double (real number) value. Although methods are available for converting from int or double to a 
String, the easiest way of doing this conversion is by joining the number to empty double quotes.

3.4.1 Methods of the Math Class 
There are some mathematical operations, such as square root ( ), which do not have operators in 
Java (i.e. they do not have corresponding symbols on the keyboard, such as * or %). For these 
operations, we must use methods.  
The developers of Java have written a class called Math which contains useful mathematical 
methods. An important skill in programming is to find and use methods that have already been written 
to achieve your goal before you try to code your own solutions. 
The Math class is different to the Gogga class. The methods are static and are called using the class 
name. No object needs to be instantiated to call the methods. Each method returns the result of the 
method's execution. 
Here are some sample statements which use some of the methods of the Math class:

System.out.println("2.6 rounded off = " + Math.round(2.6)); 
System.out.println("absolute value of -16 = " + Math.abs(-16));
