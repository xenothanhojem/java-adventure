9.1 The Need for a While Loop 
A "for" loop is usually used when the number of times one or more statements must be repeated is 
known. Sometimes the number of repetitions is not known. Instead, a block of statements is repeated 
while a condition is true, or until a value changes.

The word while means "as long as". Just before the while statement, the program asks the user to 
enter an age. If the age is correct the condition will be false, and the loop will be bypassed. If the age 
is incorrect, the condition will be true, and the loop will be executed. An error message will be

9.3.3 Algorithm 
The program needs to use a loop as we want to repeat the action of adding 3 to num and displaying 
each num. We don't know how many times the loop will execute unless we start counting in 3's until 
we get to 8000, which is what we want the program to do. For this reason, a for loop is not suitable as 
we do not know how many times the loop will execute. We need to have a condition that will stop the 
loop.  
It is important that we design the while loop to terminate correctly and serve the purpose that we 
need. By using ITC, we can design a loop that will terminate successfully. 
Select num 
Initialise num  3 
Test num <= 8000 
Change num  num + 3 
We can use the table above to write the algorithm. 
begin 
    num  3 
    while (num <= 8000) 
 
num  num + 3 
 
    end while 
end 
Now we have a successful while loop that will terminate. We need to add in code to completely solve 
the problem. The variable num needs to be displayed, but should num be displayed before or after it 
is incremented by 3?

Note that that when the end of the loop is reached, the condition at the beginning is tested to 
determine if the loop must execute again. If the result of the condition is true, the loop will execute 
again, if the condition is false, the loop will terminate and line 6 (if there was one) of the algorithm 
would execute. 
The solution to Algorithm 1 produces 3, 6, 9, 12,.... while the solution to Algorithm 2 produces 6, 9, 12 
since it increases num by 3 before num is displayed. 
We could fix this by initialising num to 0 instead of 3, however as we approach 8000 and num is say 
7999, it will be incremented by 3 to produce 8002 which will be displayed and then the loop will 
terminate effectively going over the 8000 limit.  
For this reason, Algorithm 1 is the correct solution. In the while loop, the C for change should be the 
last line of the while loop. This ensures that the loop control variable is changed and then tested. In 
Algorithm 2 the loop control variable is changed and displayed even though the loop should have 
ended.

execution time. As a programmer, you will have to decide which is the best solution for a particular 
problem.

while loop using a flowchart and pseudocode. 
S Select the test variable(s) to use in the

I 
Give the test variable(s) an initial value. 
e.g. ans = Integer.parseInt 
(JOptionPane.showInputDialog ());   
or    num = 3; 
T 
Test the condition in the while heading. 
e.g. while (ans =='Y' | ans =='y')

 ... statement(s) after the loop

The While loop 
• has only the keyword while to mark the 
beginning of the loop 
• has no semi-colon after the condition 
• may not be executed at all (if the initial 
value of the test variable makes the 
condition false) 
• has its condition tested at the beginning of 
the loop statements 
• uses SITC 
The Do...While loop 
• has the keyword do at the beginning of 
the loop and while at the end (before the 
condition) 
• has a semi-colon after the condition, 
because that is the end of the loop 
• is always carried out at least once 
• has its condition tested at the end of the 
loop statements 
• uses SICT 
Both loops are carried out if the condition is true or until the condition becomes false. 
The do...while loop is used much less frequently than the while loop because you are usually not 
sure that the loop must be carried out at least once. Menus can use do...while because a menu must 
always be displayed once. 
Do while loops are useful to validate input; to ensure that the user cannot proceed in the program until 
they have entered the data.

9.8 Choosing an Appropriate Looping Structure 
There are three looping structures in Java: the for loop, the while loop and the do loop. Which 
circumstances dictate the selection of an appropriate structure?  Any one of the loops can be used in 
place of any one of the other loops. However, it is often more appropriate to use one type of loop in a 
particular situation.  
Consider the following code using a while loop for items sold at the flea market: 
int itemCount = 0; 
char ans = JOptionPane.showInputDialog  
      ("Has an item been sold? 
(Y/N)").charAt(0); 
while (ans == 'Y' | ans == 'y') 
{ 
    itemCount = itemCount + 1; 
    ans = JOptionPane.showInputDialog ("Has an item been sold?  
          (Y/N)").charAt (0); 
} 
System.out.println ("The total number of items sold is " + itemCount); 
The same code can be written using a for loop. Recall that a for loop has three parts: initialise a 
variable, test a condition and change the loop variable. For example,  
int itemCount = 0; 
char ans; 
 
for (ans = JOptionPane.showInputDialog 
     ("Has an item been sold?(Y/N)").charAt (0); 
     ans == 'Y' | ans == 'y';  
     ans = JOptionPane.showInputDialog 
     ("Has an item been sold?(Y/N)").charAt (0);)  
     itemCount = itemCount + 1; 
} 
System.out.println ("Total number of items sold is " + itemCount); 
Although the above use of the for loop produces the correct output, we do not recommend that you 
use a for loop in this way. We feel that in the case of problems where the number of iterations is not 
known beforehand, a while loop results in code which is more intuitive and more readable. 
In the same way, a problem coded with for loop can logically always be rewritten with a while loop or 
a do-while loop and vice versa. The decision of which loop to use is therefore an issue of code 
readability, rather than what is possible.  
We recommend the following: 
• Use a for loop when the number of iterations is known beforehand. 
• Use a while loop when the number of iterations is not known beforehand.  
• Use a do while loop where at least one pass through the loop must be made.
