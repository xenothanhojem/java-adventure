5.1 What is a Network? 
A network consists of two or more devices called nodes that are connected by some type of 
communications channel. A node is any device connected to the network. While a node is typically a 
computer, it can also be something like a printer or a mobile device. The communication channel can 
be either bounded using wires or unbounded using a form of wireless technology.  
One node in a network could be a server. A network server is a computer designed to act as central 
network computer that provides various resources like network security, hardware access, disk 
space, printer access. The server has server software which manages logins and user access to 
computers on the network. Network devices such as printers and routers to name a few are 
connected network and managed by the server. Many uses can print to centralised printers and 
access the Internet. A server may manage and provide resources to several LANs which are 
connected to it. 
A network which exists in a geographical area such as a home, school, computer laboratory, office 
building or group of buildings is called a Local Area Network (LAN).

The trend today is not for companies to set up LAN networks using expensive devices and servers, 
but rather to use cloud computing. Cloud computing is making use of computing services like 
storage, databases, software, networking and more over the Internet, “the cloud”. You pay only for the 
services that you use, removing the need to upgrade servers and software. Cloud services are 
lowering the cost of computing for individuals and businesses.

5.2 Nodes 
The nodes on a network can be a: 
• device that users use such as a laptop, desktop or mobile device 
• device to connect nodes to each other, namely a switch 
• device to connect to the Internet, such as a router 
• device to provide a service such as a server or a printer 
A switch connects nodes in a network using communication media such as cables. Each node is 
connected to the ports in the switch. The server and printer are connected to the switch so that each 
node can print and access the server.

5.3 Communication Media 
Irrespective of the distance covered by a network, it has 3 parts.  
• firstly, hardware that acts as a source or sender,  
• secondly, hardware that is the destination or receiver and  
• thirdly, some sort of connection between source and destination.  
 
https://scienceaid.net/Computer_Network 
The connection is usually called the communication channel or transmission medium. The 
sending and receiving devices can each be any node such as a computer, a cell phone, a printer, or 
any other networkable device. 
A communication channel has a bandwidth, which is the maximum amount of data that it can transfer 
per unit time (usually the quantity of bits per second). The rate at which data is transferred over a 
communication channel is usually measured in thousands of bits per second (kilobits per second 
Kbps), millions of bits per second (megabits per second Mbps) or billions of bits per second 
(gigabits per second Gbps). The higher the bandwidth the faster the transmission rate. 
Bounded communication channels, consisting of physical cabling, are commonly used for wired 
LANs, while unbounded media, with no cables, carry signals for wireless LANs and larger networks. 
5.4 Bounded Media 
5.4.1 Unshielded Twisted Pair (UTP) 
The most common bounded media cabling in small LANs is 
Unshielded Twisted Pair (UTP) cabling, which consists of several 
pairs of twisted wires in an outer protective plastic cover. The 
twisting of the wires helps to eliminate interference from signals on 
other wires and from other electrical devices.

5.4.1.1 Problems with Copper Cables 
Attenuation: The signal loses strength over a distance. 
Electro-Magnetic Interference: Signals from other sources such as machinery can corrupt the 
signals traveling in copper cables nearby. 
Eavesdropping: Signals traveling along copper cables can be intercepted by outsiders. 
Crosstalk: Signals in adjacent wires can interfere with each other as in a crossed telephone 
conversation. 
5.4.1.2 Advantages of UTP 
• It is inexpensive and easy to install 
• it supports fast transmission rates 
• It is widely used and tested 
• It can be used in many different types of networks 
5.4.1.3 Disadvantages of UTP 
• It is susceptible to interference from other devices. 
• Crosstalk can be a problem when signals on wires close together corrupt each other. 
• There are distance limitations. A cable can be a maximum of 100m before the signal 
degenerates due to attenuation. A device called a repeater can be used to join two long 
lengths of cable. A repeater will boost or amplify the signal on the cable. 
5.4.2 Shielded Twisted Pair (STP) 
There is a more expensive, bulkier type of cable called 
Shielded Twisted Pair which has twisted pairs enclosed 
in protective foil. This type of cable is less affected than 
UTP by interference and crosstalk.

5.4.3.1 Advantages of Fibre Optic Cable 
• It supports much faster transmission rates because light travels faster than electronic signals. 
• It is more secure than UTP since light signals cannot easily be tapped. 
• It can transmit over much longer distances than UTP because the light signals do not weaken 
like the electronic signals in copper wires. 
• Light signals are not susceptible to interference unlike electronic signals which are very 
susceptible to EMI. 
• The light signals are also immune to lightning and electrical surges.

5.5  Unbounded Media 
5.5.1 Wireless Networks  
Nodes in a network do not have to be connected with cabling. Wireless 
networks use the air to transmit radio signals such as Bluetooth, infrared 
beams, microwaves, satellites or laser light signals. Each type of wireless 
signal uses a different frequency (measured in Hertz or cycles per second) so 
that the signals remain separate from each other.

5.5.2 Types of Wireless (Unbounded) 
Transmissions 
5.5.2.1  Microwave Transmissions - Long 
Distances 
Microwave transmissions can either be terrestrial (land-
based) or satellite (above the surface of the earth).  
Terrestrial microwave systems use the line-of-sight method 
for transmitting data between two antennas and can transmit 
over ranges of 50 km provided there is no obstacle in the way.  
Satellite transmissions use satellites orbiting the earth to receive and pass on communications to 
the destination. 
Satellites have transponders which transmit signals 
they have received to stations on the ground below. A 
transponder is a device which receives signals and 
converts them into a different frequency, boosts the 
signals and then sends them to a station on the ground 
below which must be in line-of-sight of the satellite.

These rotate around the earth every few hours. Low-orbit satellites are better for interactive

5.6 Network Classification 
Networks can be classified according to the distances covered as in LAN, MAN, WAN, GAN, PAN 
and HAN.  
5.6.1 Local Area Network (LAN) 
A LAN is a network setup in a limited physical location such as in a building, or on a campus. A 
school network with computers connected in many different locations is a typical example of a LAN, 
as shown in the diagram on the right. 
5.6.2 Metropolitan Area Network (MAN) 
A MAN is made up of LANs interconnected using high-speed connections across a city or 
metropolitan area. A MAN would be used by a company with offices scattered across a city. 
www.c2kni.org.uk/future/wan1.htm 
5.6.3 Wide Area Network (WAN) 
A WAN is made up of interconnected LANs and/or MANs 
in different cities or different countries. A large company 
such as Edgars or a bank with branches in many cities 
will use a WAN. The WAN of a large company is often 
called an enterprise WAN. 
5.6.4 Global Area Network (GAN) 
A worldwide WAN such as the Internet is called a GAN.  
www.soi.wide.ad.jp 
5.6.5 Personal Area Network (PAN) 
The PAN is used by an individual for communicating between devices such as a desktop computer, 
Laptop, smartphone, smart wear and tablet. A PAN exists where a user transfers data and 
synchronises data between cell phone, laptop, printer, camera, wearable devices and many other 
devices.

5.6.6 Home Area Network (HAN)

devices that are wired into the network. The PAN's of the individuals in the home, sharing resources

A firewall is a system designed to prevent unauthorized access to or from a private network. You can 
set up a firewall in either hardware or software form, or a combination of both. Firewalls prevent 
intruders on the Internet from accessing a private network which is connected to the Internet.

5.8 Client-Server Network 
5.8.1 Role of the Server 
A server computer is a computer which shares resources with other computers in a network. The 
computers that connect to the server are called client computers because they use the services of the 
server. In a client/server network there may be several servers, each with a specific purpose, 
depending on the resources the server shares. For example, there may be:  
• a file server with large hard disk capacity can store many files which can be accessed by 
network users.  
• a print server to which one or many high-speed printers are attached. These printers can be 
shared by computers on the network. 
• a web server is usually a combination of hardware and software which accepts requests for 
web pages and sends the pages to the client machines.  
• an email server stores incoming mail for distribution to users on the network and sends out 
outgoing messages.  
• a proxy server is a server through which all web content passes. It is positioned between the 
client computers and servers and it intercepts and checks all traffic maintaining security by 
disallowing access to unauthorised users. It also stores web documents, in a process called 
caching, that have been previously accessed, in order to speed up download time. If a

5.8.1.1 Local Servers vs Cloud Servers 
Organisations have the choice to use local servers, servers located in the organisation, or to use 
cloud servers.  
Having a local server means that the company has physical control over their server setup and 
storage of critical data. There is no need to rely on the Internet connection for access to the server 
and data. This also means that you need to have the expense of setting up and managing the server 
by IT staff.

5.8.2 Role of the Client 
The functions of an operating system on a client computer (or workstation) in a client/server network 
must enable the client computer to connect to the server and use the resources of the server.  
The server should not be used as a workstation; its purpose is to provide services to the computers 
on the network. The server in the network will have advanced functions which allow it to manage all 
the users and computers connected to it.  
Some functions of a server operating system include: 
• Storing and maintaining details of users (with their logons and access rights). 
• Enabling computers to connect to/disconnect from the network, allocating IP addresses as 
necessary. 
• Allowing file and printer sharing. 
• Monitoring all traffic on the network. 
The server should have higher hardware specifications that the clients, such as a faster processor, 
more RAM and more local storage.  
5.9 Network Access Control (NAC) 
Any computer accessing a network will only be able to access the network if the settings of the 
computer and the login of the user complies with the protocols (rules) of the network. When potential 
users log onto the network, they are authenticated by verifying their logon information. They will also 
be restricted in terms of the data that they can access. User profiles and permissions were previously 
discussed in Learning Unit 4.3.1 
Access to the network will be given according to profile of the user. Once a user is authenticated, 
rights are awarded to the user according to the user's profile. The user will be allocated permissions 
to use certain resources on the network. For example, a student on the school network will only have 
access to student files, they may not be able to change settings of the workstation or access the

5.10 Advantages of Using Computer Networks 
5.10.1 Communication 
Networking allows for ways of communication that would be previously impossible. Instant messaging 
such as email allows users to talk in real time and send files to other people wherever they are in the 
world. It facilitates the sharing of ideas, facts, news events and research. 
5.10.2 File Sharing 
File sharing enables a computer user to access a file saved onto 
another computer within the network. A person sitting at one 
workstation of a network can easily see the files on the other 
workstation, as long as he/she is authorised to do so. File sharing saves 
time which is wasted in copying a file from one storage system to 
another, by using a storage device, such as a hard drive. Many people 
can access or update the information stored in a database, ensuring 
that it is up-to-date and accurate. File sharing also allows the sharing of 
storage memory. When many computers are on a network, memory of 
different computers can be used for storage. By placing a storage 
server on the network huge storage capacity can be made available to 
those using the network.  
http://www.johnpopes.com/wp-content/uploads/2009/01/file-sharing.jpg 
5.10.3 Printer and Resource Sharing 
Expensive devices such as printers and routers can be 
shared by computers in a network. For example, in a 
home if several people, each having their own 
computer, wished to access the Internet or print, at the 
same time as each other, they would require four 
routers and four printers. A computer network would 
be cheaper as all the four computers can be 
interconnected, and just one router and one printer 
can provide the services to all four users.

5.10.5 Data Transfer 
When accessing or storing data on local servers or in the cloud, data needs to be transferred from 
one device over a network. Data transfer rate is the amount of data that can be sent between two 
points on a network in a given time. This is very important in networks. Transferring large amounts of 
data to cloud storage would not be a good idea if you have a low transfer rate. The setup of the 
network and the type of network hardware installed will have an impact on the data transfer rate. The 
transfer of data over the Internet will also depend on the bandwidth which is available. The bandwidth 
is the maximum transfer capacity of a certain point on the network.

Computer networking has made global communication possible on a grand scale. This has improved 
the productivity of individuals and businesses by making communication fast and efficient. The 
Internet has made information easily accessible and enabling the collaboration of people to build

scratch. Cloud storage and remote access of data enhance productivity as data is easily available and 
easily shared. 
Email was the first form of global communication to change the way businesses communicated. 
Today businesses rely on far more than email to improve productivity. Not only can documents be

calendars, surveys, making team video calls, task organisers to name but a few.  
5.11 Disadvantages of Computer Networks 
The section below is a brief outline of the disadvantages of computer networking. These concepts will 
be discussed in greater detail later on. 
5.11.1 Security Issues 
Networked computers are more susceptible to unauthorised access than stand-alone computers. 
Computers on a network need additional network security software to prevent the theft of any 
confidential and private data. Users working on a network will be allocated rights to enable them to log 
onto the network and they are allocated access to specific devices (like printers) on the network. Their 
Internet access may be filtered depending on the policy of the organisation, not allowing access to 
certain sites. Control of access to the network from within the organisation as well as from outside the 
organisation the is one of the key issues to maintaining good security. 
5.11.2 Spread of Computer Viruses 
If any computer in a network gets affected by a computer virus, there is a possibility that other 
computers may become affected too. The spread of viruses on a network is rapid as all computers 
are connected. This problem is compounded when the network is connected to the Internet. 
5.11.3 Cost 
The initial set up cost of a computer network can be high. Expensive devices like routers, switches 
and file servers may be required. Workstations would need network interface cards if they don't have 
built in network cards. In addition, the computers would need to be connected using cables. Should 
you choose to connect the computers using wireless technology, you will need a device called a 
wireless access point to send out wireless signals and the computers must either be able to receive 
wireless signals, or you will need to buy wireless network cards. Cloud storage can reduce the cost
