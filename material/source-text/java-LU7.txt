7.1 Coding Programs with If Statements 
In Java, we can make decisions using an if statement. The format of this statement is: 
if (<condition>) 
{ 
   <statements if true>  
} 
 else 
{ 
   <statements if false> 
} 
The words if and else are reserved words and your IDE may indicate this by putting them in a 
different colour.

In Java, the | symbol (usually above the backslash (\) on the keyboard) is used to stand for the 
logical operator OR; the & symbol is used to stand for AND the ! symbol is used to stand for NOT. 
(Similar to != stands for ≠ (not equal to)). 
Why are 'a' and 'A' not the same in Java?  When Java compares the 2 letters, it compares their 
Unicode code values and not the actual characters. Since 'a' and 'A' do not have the same 
Unicode values, the computer sees them as 2 totally different characters.  
A similar thing happens when words are compared - the computer checks each letter of a word, 
looking at its Unicode value. 
When more than one condition is tested, brackets are put around the whole condition. It is also

7.6  Important Points on Logical Operators 
The AND (&) operator means that 
both parts of a condition must be 
true for the condition to be true. 
The OR (|) operator means that ANY 
one part (or the other part) of a 
condition must be true for the 
condition to be true. 
To apply NOT to part of a condition, 
put it in another set of brackets 
inside the "main" condition brackets. 
The NOT operator(!) makes a 
condition become opposite. 
If you want Java to execute an OR 
operation before an AND, then you 
need to put extra brackets around 
the OR condition. (It will then do the 
brackets first) 
In this case, we are checking if the 
user wants to play again (y or Y) and 
if s/he has not had five chances yet. 
Each part of the condition must make sense on its own. 
It is not correct Java syntax to put: if (age > 25 & < 38) 
The correct syntax is:    if (age > 25 & age < 38) ... 
 
if (age > 29 &  age < 40)      
    { System.out.println("Thirty something"); } 
if ( price > 100 & !(quantity_bought < 5) )  
    { discount = 10/100; } 
if (age < 16 | age > 65 | has_job == 'n') 
 
    System.out.println("You pay half price"); 
if ((ans=='y' | ans=='Y') & (no_of_chances<5) 
    result = "Play again"; 
 
 
The condition must always be placed in brackets 
after the word if. Each part of a condition can also 
be bracketed: 
if ((age > 25) & (age < 38)) is the same as     
if (age > 25 & age < 38) 
The statement     if (age > 25 & age < 38)   without 
the inner brackets is valid because the operators 
AND OR have a lower precedence than the 
comparison operators.  
Java will always carry out logical operators in the 
following order: 
1st: Brackets 
2nd:  NOT 
3rd:  AND 
4th:  OR  
if they appear in the same statement.  
You can use more than one AND, OR, NOT in a 
statement. If they are the same, they are 
evaluated from left to right. 
Strictly speaking, && should be used 
instead of &, to make your programs 
more efficient. 
 && is called a conditional AND, 
because it only evaluates the 
second part of a condition if the first 
part is true.  
& is called a Boolean AND, 
because it evaluates both parts, 
even if the first one is false. 
If a double && is used: (a > b && a > 0) the first part will be 
checked and only if it is true, will the second part be checked. 
In (a > b & a > 0), a > b is false, but because a single 
& is used, a > 0 will still be checked, even though the whole 
condition will be false.  
In (a > b && a > 0) as soon as a > b is found to be false; 
the whole condition is false. The second part of the condition a 
> 0 is not checked. 
The same applies to OR ( || is better than | ). 
It is more efficient to use the conditional OR (||) 
instead of the Boolean OR (|). 
Like the && operator, using || means that the 
second part of a condition will not always be 
evaluated. If the first part is true, the whole 
condition is true, because with OR, as long as one 
part is true, the whole condition is true.

7.6.1 Negating the Condition in an If Statement 
Sometimes an if statement has been coded with exact opposite of a condition. The condition can be 
made to be the opposite by placing a NOT (!) sign in front of the condition, but then this will change 
meaning of the if statement. To solve this problem, the then part and else part of the if statement 
must be swopped around. 
    begin 
        if (<condition>) 
              <statementA>; 
        else 
             <statementB>; 
    end 
    begin 
        if (! <condition>) 
            <statementB>; 
        else 
            <statementA>; 
    end
