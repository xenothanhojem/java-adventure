8.1.3 How Strings are Compared 
When the computer compares Strings, it looks at each character individually. Each character has a 
numerical code value in the Unicode table and so, instead of comparing letters, the computer is really 
comparing Unicode code values which are numbers. 
 If the words are not the same length, it will add the necessary spaces on the end of the shorter word 
before comparing the words. 
 In the code if (stg1.equals (stg2)), the Unicode values of each character in each word are

8.4.1 How a Switch Statement Works 
When a switch statement executes, the interpreter computes the value of the expression in brackets 
after the word switch, then looks for a case label that matches that value. If it finds a match, the 
interpreter starts executing the block of code at the first statement following the matching case label. 
If it does not find a matching case label, the interpreter starts execution at the first statement following 
the default: label. Or, if there is no default: label, the interpreter skips the body of the switch block 
altogether and carries on with the rest of the program.  
The use of the break keyword at the end of each case clause causes the interpreter to exit the 
switch statement block when it has executed the statements in that case clause. The case label 
which matches the switch expression is only the starting point of the desired code. The individual 
cases are not independent blocks of code and with breaks, they do not have any implicit ending point. 
Therefore, the end of each case clause must be specified using a break statement. 
8.4.1.1 Investigation of the Break Statement 
 To understand the importance of the break statement, place // before each break; in the switch 
statement and run the program with 78 as data.  
 Write down the output. 
In the absence of break statements, a switch statement begins executing code at the first statement 
after the matching case label and continues executing statements until it reaches the end of the 
switch block. 
A simple explanation is that the program finds the first matching case label starting from the 
beginning of the switch statement. In this example, the grade should be displayed as a 'B'. 
Because there are no break statements to cause the program to exit the switch statement after 'B' 
has been assigned, each statement after the grade = 'B' is executed one after the other, 
assigning each letter in turn to the variable grade. 
The final grade is assigned is an 'F' as all the previous values are overwritten.

8.5.1 Important Points on Boolean Expressions 
 
 
Boolean variables can only store the results of 
Boolean expressions. i.e. expressions that test a 
condition. 
 
boolean even_no; 
 
if (num % 2 == 0)  
   {even_no = true;} 
boolean even_no; 
 
even_no = (num % 2 == 0); 
The Boolean variable will always get a value 
(either true or false) when the statement has 
been completed. 
In the if statement above, even_no will not get a 
value if num is odd, but in the Boolean 
expression, it will get a value. 
 
 
Any condition in an if statement can be rewritten 
as a Boolean expression and vice versa. 
 
Boolean variables only have two values: TRUE 
and FALSE 
 
    In Java, we can think of  
   FALSE = 0 and TRUE = 1. 
 
The results of Boolean expressions are not 
Strings so don't put true or false in quote marks. 
 
Many computer programmers think that it is 
better programming to use a boolean variable 
rather than an expression in an if statement. 
 
boolean teenager; 
int age; 
 
teenager = (age > 12 & age < 20); 
 
if (teenager) { ... } 
 
Boolean variables are often used with the logical 
operators AND, OR, NOT. 
Boolean variables are useful when the condition 
in an if statement is very long. 
if (let=='a' | let=='e' | let=='I' | let=='o' | let=='u') 
   { System.out.println ('The letter is a vowel'); } 
vowel = (let=='a' | let=='e' | let=='I' | let=='o' | let=='u'); 
if (vowel)  
   { System.out.println ("The letter is a vowel"); }
