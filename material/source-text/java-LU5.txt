Learning Unit 5 For Loops 
Pattern recognition is an important part of computational thinking. Most programming languages have 
special statements to repeat code. Once a programmer has identified the code to repeat and the 
number of times this repetition must take place, the programmer can create a single statement known 
as a for loop to repeat code a set number of times. In Java, a for loop is known as a counting loop.

5.3 Explaining For Loops 
A for loop is the most frequently used type of loop in Java. It is also called a counting loop as it repeats a section of code a fixed (or countable) number of 
times. 
The initialiser is also called the loop control 
variable.  
This initialiser variable is usually an 
integer (or a char), as it counts the 
number of times the loop repeats E.g. 
1,2,3, ...  
The loop control variable is also declared 
here in the brackets, as it is only valid in 
the for loop. Traditionally the letter 'i' is 
used as the loop control variable, but other 
more meaningful variable names such as 
count or loop are also used. 
The three parts in brackets after the word 
for are three separate statements, so 
there must be a semi-colon after each of 
these statements, inside the for brackets. 
A semi-colon ends a Java statement.  
The first statement in the for loop header 
initialises the variable, the second tests it 
and the third increments it. These three 
stages are needed to code a for loop that 
should terminate. 
All the statements that must be repeated 
are enclosed in the opening and closing 
curly brackets.  
The syntax of a Java for loop is: 
for (int initialiser; condition; increment)  
{  
  //statements to be repeated  
  //in the loop  
} 
The syntax of the for loop in the previous example is: 
 
for (int loop = 1; loop <= 5; loop++) 
{ 
     System.out.println ("The loop has been  
        carried out " + loop + " time(s)."); 
     System.out.println (); 
} 
System.out.println ("The loop has ended 
                                     now."); 
The variable loop is initialised to 1. The value in loop is 
tested every time the loop carries out. The value in loop 
changes by one every time.  
 
Each time the loop is carried out (called a 
pass of the loop) a boolean condition is 
tested to see if the final value has been 
reached. The loop will be run again if the 
test returns true. The loop will end when 
the test expression returns false.  
With each pass of the loop, the value of 
the loop control variable is incremented 
(increased). 
There must NOT be a semi-colon after 
the round closing bracket here, otherwise 
nothing will be repeated in the loop. If a 
semi-colon is put there, the statements in 
the curly brackets will be carried out once 
only.  
loop = loop + 1 can also be written as 
loop++ which reads "loop plus"

5.10 Calculating the Average 
To find the average of a group of numbers, we can calculate the sum of these numbers and then 
divide the sum by the number of numbers in the sequence. 
In this case the user will enter 10 numbers and we will code a program to input the numbers and 
determine the sum and hence the average using the sum and then dividing by 10. We will not be able 
to store all 10 values simultaneously with a single variable num. If we wanted to store all 10 values, 
we would need a special data structure such as an array which we will learn about in Grade 11. We 
can however use a single variable num to store the first value of num, in the loop, and then add the 
value of num to sum straight away. The next time the loop is run, we input the next value entered by
