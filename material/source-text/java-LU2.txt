2.1.2 Variables 
Variables can be thought of as boxes in memory. Each variable (or box) can only store one item of 
data of one data type. In Java, each variable has a data type. The data types that are commonly 
used are integers (whole numbers), real numbers (numbers with decimals) and Strings (text data). 
Each of these types store different data and take up a different amount of space in memory. It is 
important to tell Java what data type a variable will be so that it knows how much space in memory to 
allocate for each variable.

2.1.3 Assignment Statements 
The following Java statement is called an assignment statement. 
 subject = JOptionPane.showInputDialog ("Enter the subject");  
It contains an equals sign that does not have the same meaning as an = in Mathematics. In Java, the 
(=) equals sign is used to store what is on the right-hand side of the equals into the variable on the 
left-hand side of the =.  
We say that the subject variable has been assigned (or gets) a value. The value that it is assigned 
has been produced (we say returned) by the showInputDialog method. 
Every variable has 3 characteristics: 
• an identifier or name; 
• a data type, stating what type of data can be stored in it; 
• a value that is stored in it. 
In a program, every variable that is used must be  
• declared (created) given an identifier and a data type 
• given a value   this is done using an assignment statement.

Numeric data such as integer numbers and real numbers are stored in the computer's memory in 
different sized boxes to Strings.  
Integers are positive and negative whole numbers and zero, with no decimal places. They are 
different from real numbers, which are numbers with a decimal point. 
Examples of integers:   −55 7 0 −1 
Examples of real numbers:  2.5 −0.000879 6523.4  −77.99 
In Maths, the set of real numbers includes the set of integers. In programming, the 2 types of numbers 
are separated because the computer deals with them in different ways.

2.1.7 Identifier Names 
The names or labels given to variables, methods and classes are called identifiers. Some of the 
identifier names we have used are num1, showInputDialog and MakeSquare. 
2.1.7.1 Rules for Variable names/identifiers  
• Identifiers can contain numbers but may not start with a number. 
• Spaces are not allowed in a variable identifier. 
• No special characters (such as %, @, *, −, " ) may be used in an identifier. 
• Reserved words (keywords that have a special meaning in Java) may not be used.  
By convention,  
• identifiers of variables and methods in Java start with lowercase letters.  
• identifiers that are names of classes start with a capital letter. 
• the identifier should reflect the contents of the variable, method or class. 
• any identifier that contains more than one word must have the words joined together using 
camel case. This means the first letter of each word (after the first) is a capital letter − for 
example, instead of num1 we could have used the identifier firstRealNumber. (This is not a rule, 
but a convention to make identifiers more readable.) 
It is essential that you follow the rules for identifier names. It is also important to follow the 
conventions as they make your program readable for other people and easy to understand. Most 
people use the standard conventions so that if they make their programs publicly available, others will 
understand them. 
The following are valid variable identifiers and follow conventions:  num2,  firstName,  fieldWidth,  ch 
The following are NOT valid variable identifiers:  2num,  first name,  char,  tel-num 
The following are valid but do not follow conventions: FieldWidth (for a variable), a (for a person's 
name), firstname.

2.2 Java Primitive Data Types 
Refer to Learning Unit 1 in Exploring IT: Theory Grade 10 for more details about binary and 
hexadecimal numbers and calculations relating to the maximum and minimum numbers in a fixed

Java has several primitive data types, of which int and double are examples. The primitive data type 
char can store a single character such as 's', '$' or '7'. Note that letters, numbers and 
punctuation are all considered to be characters. In Java, a char value is enclosed in single quotes.  
The different data types and their properties are summarised in the table that follows. This table is 
provided for reference purposes - you will come across most of these types sooner or later.  
A char variable in Java, strictly speaking, is represented with Unicode instead of ASCII code. ASCII is 
an old system that used 8 bits to store a character and Unicode stores a character in 16 bits, however 
the first 127 characters of Unicode are the same as the first 127 in ASCII, so we often interchange 
these terms.

representation. \u0000 corresponds to 0000000000000000 in binary and \uFFFF corresponds to

A boolean data type can store a true or a false and can be used to store the result of conditions or 
values that are yes or no.

2.2.1 Declaring Variables 
There are two main types of variables used in Java programs: 
• a variable of a primitive data type, i.e. the name given to a storage location which will hold a 
value of a primitive data type, such as an int or a double. E.g. int num = 564; num is a 
variable of the primitive data type, int. 
• an object reference, i.e. the name of an object, such as bug (a Gogga object) or str (a String). 
Objects are stored differently in memory to primitive type variables. 
All variables in a program must be declared by stating the type of the variable (either a primitive type,

2.3.1 DIV and MOD in Java 
Java has a mod operator that is depicted with a percentage sign % and finds the remainder after the 
first number has been divided by the second. For example, 5 % 2 = 1, 16 % 2 = 0 and 25 % 7 = 4. 
DIV is called integer division and depends on the types that it is working with, so does the division 
operator. If the division operator occurs between two int types, integer division will be performed, 
where the remainder is ignored, and the result is an integer. For example, 12/5 = 2 and 16/3 = 5 and 
9/3=3. 
When division takes place between two real numbers, or one real number and one integer, the result 
will be real and is considered as real division. For example, 5.0/2 = 2.5, -12.6/5.2 = -2.423 and 
9/20.5 = 0.439. As long as one of the numbers in the division is declared as a real number, the result 
will be real and should be assigned to a variable declared as double. 
The type of the variable that the result is assigned to does not influence the division.  
For example, double ans = 5 / 2; will produce a result of 2.0 since 5 / 2 will be 2 and 2 will be 
converted to a double when it is assigned giving 2.0.

2.3.3 Compound Assignment Operators 
The simple assignment operator is the equal sign (=). You have seen many examples of its use. The 
expression on the right of the assignment is evaluated and its value is assigned to the variable on the 
left, e.g. 
 x = a + 2*b – 3*a*c; 
  n = n + 1;          // increase the value of n by 1 (or n++) 
Note the direction of the assignment: from the right-hand side of the equals sign to the left; the 
variable on the left changes. It is a common programming error to get the assignment the wrong way 
around, as in 
 n + 1 = n;       // wrong way!  wrong way!  wrong way! 
Java expects a single variable on the left-hand side and will give an error message if it finds anything 
else.

2.3.5 Order of Arithmetic Operators 
The order of operations in Java follows a set of strict rules. The computer works out arithmetic 
expressions in this order: 
 FIRST    Brackets 
 SECOND  *, /, (both integer and real division), % 
THIRD   +, − 
Operations with the same importance are evaluated from left to right, as they appear in the 
expression. 
Example 1 
  4 + 5 * 3 - 12 % 5 
= 4 +  15   -     2 
=   19      -     2 
=      17 (Integer) 
Example 2 
   (10 + 4) / (25 - 2 * 11) 
=     14    /  (25 - 22) 
=     14    /   3 (Integer Division) 
=         4 (Integer) 
 
Example 3 
    (10 + 4) / (24 - 2.2 * 11) 
=     14    /  (24- 24.2) 
=     14    /      -0.2 (Real Division) 
=         -70.0 (Real)
