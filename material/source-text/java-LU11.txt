11.1 Decomposing a Problem with Methods 
Methods can be used to subdivide code into sections or tasks. We can use these methods to reflect 
the tasks into which the problem is decomposed. For example, the earlier problem to draw the 
Pyramid could be decomposed into three tasks: 
1. draw up steps 
2. draw down steps 
3. draw horizontal line 
 
The solution could be written by separating the tasks using comments shown in bold and blank lines.

11.2 Optimising the Problem to Reuse Methods 
Programs often contain code that is repeated. Usually we use loops as a structure to duplicate code, 
but methods can be used effectively to group similar statements that can be called repeatedly.

11.3 Advantages of Methods 
Methods provide a structured approach to solving problems. It can be considered as a divide and 
conquer strategy and, before object-oriented programming, was a significant methodology to problem 
solving defined by the term structured programming. 
Object-oriented programming was an improvement on structured programming and will be explored in 
more detail in Grade 11. 
Using methods in a more complex program have many advantages: 
• Methods are useful to decompose a large program into defined separate tasks. We can zoom 
into each method and focus on the code for each task.  
• Coding with methods aids locating errors.  
• If you use descriptive method names, a programmer can look at the main method and have a 
general understanding of the program aiding readability. 
• Code that is often reused can be placed in a method to reduce repetition of code. 
Generally, a method should have three or more lines of code.

Methods can provide clarity in programs with nested loops. The inner loop can be placed in a method
